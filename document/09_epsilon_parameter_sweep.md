# 固定しきい値基準の比較：1e-6〜1e-16

## 1. 結論

**今回の6箇所は、機械イプシロンでなければならない処理ではない。型に依存しない固定値を、調整可能な定数として使える。** 機械イプシロンは現在の既定値を決める基準である。前回の`1e-6`の試験は、その設定で精度・収束が変わることを示したものであり、固定値化そのものを否定する根拠ではない。

今回、`1e-6`から`1e-16`までの11設定と現状を比較した。

- **GMRESでは、小さい固定値で改善する実例を確認した。** 近breakdown条件の12件では、`float`の正解数が現状の2件から`1e-15`／`1e-16`の10件へ増えた。通常の20件／型では、全固定値で解の誤差と反復数が現状と同じだった。
- **固有値・固有ベクトルでは、値と用途によって結果が異なる。** 既定数学構成の追加試験では、共通値`1e-7`で各型とも全22件の固有値と一般ソルバ全16件の固有ベクトルが収束と判定された。ただし、許容誤差も緩めているので、収束件数の増加は精度向上を意味しない。
- **共通値を小さくするほど全用途が良くなるわけではない。** `float`では`1e-12`以下で固有値計算2件が上限まで反復して未収束となった。既定数学構成の`double`固有値誤差は、今回の入力集合では`1e-8`以下にしても最大約`3e-7`でほぼ一定だった。
- 製品設定では、GMRES breakdown、固有値の許容誤差、固有ベクトルの許容誤差、逆反復シフト、内側GMRESの許容誤差を**用途別の固定定数**に分ける設計が適している。1個の共通定数も使用可能だが、各用途の変更が連動する。

この調査では本体ヘッダ・既定値・includeを変更していない。以下の数値は定数値選定の材料であり、全入力・全マイコンでの保証ではない。

## 2. 比較条件としきい値の意味

比較元はcommit `8e22c7b327fa4d783a0db33527cc25b5d941b8ba`。本体ヘッダの隔離コピーで`std::numeric_limits<T/Real>::epsilon()`の6箇所だけを同一の固定値`e`へ置換した。係数8・32・16、分母保護値、各反復上限は変更していない。

- C++11、g++ 15.2.0、`-O2 -Wall -Wextra -Werror`。
- `float`／`double`を比較。基準の機械epsilonは、それぞれ約`1.1920929e-7`／`2.2204460e-16`。
- `default`は組み込み向けの既定数学構成。`std`は`BASE_MATH_USE_STD_MATH_`を定義したホスト比較用構成であり、ターゲットへの`<cmath>`追加ではない。
- GMRES追加試験1536件、固有値追加試験1056件、用途別試験440件。別途、既存GMRES／固有値回帰試験を12設定×2数学構成で実行した。
- 生データ、ソース・依存先ハッシュ、設定は[測定データ](../test_vs/algorithm_improvements/results/epsilon_parameter_sweep/README.md)に保存している。

| 用途 | 固定値`e`を入れた場合の実際の式 |
| --- | --- |
| GMRESのArnoldi breakdown | `||w_after|| <= 8 * e * ||w_before||` |
| 一般固有値のdeflation | 絶対許容誤差に`8 * e * local_scale`を加えたしきい値で非対角成分を判定 |
| 対称固有値Jacobiの停止 | 絶対許容誤差に`8 * e * matrix_scale`を加えたしきい値で回転を省略 |
| 一般固有ベクトルの収束 | 入力最大成分で正規化した残差`<= 32 * e` |
| 逆反復シフトの既定係数 | `max(1e-6, sqrt(e))`。その後、入力scaleを掛けて分母保護値を下限とする |
| 内側GMRESの既定相対許容誤差 | `16 * sqrt(e)`（`gmres_k_decay_rate > 0`なら指定値を優先） |

## 3. GMRES：固定値を下げることで改善した例

次の族を、`delta = 2e-6, 2e-8, 2e-10, 2e-12, 2e-14, 2e-16`で比較した。

```text
A = [[1,     0],
     [delta, delta]]
b = [1, 0]
真の解 x = [1, -1]
```

各deltaで直交化1回／2回を試し、合計12件／型。`K=2`、`cycles=1`、相対・絶対許容誤差は0、`division_min=1e-25`。下表の「正解」は、厳密な格納入力に対する相対前進誤差が`float <= 1e-6`／`double <= 1e-12`の件数であり、一般的な成功保証ではない。反復数は12件のArnoldi更新数の合計。

| --- | --- | --- | --- | --- |
| 現状の機械epsilon | 2/12 | 14 | 10/12 | 22 |
| `1e-6` | 0/12 | 12 | 0/12 | 12 |
| `1e-7` | 2/12 | 14 | 2/12 | 14 |
| `1e-8` | 2/12 | 14 | 2/12 | 14 |
| `1e-9` | 4/12 | 16 | 4/12 | 16 |
| `1e-10` | 4/12 | 16 | 4/12 | 16 |
| `1e-11` | 6/12 | 18 | 6/12 | 18 |
| `1e-12` | 6/12 | 18 | 6/12 | 18 |
| `1e-13` | 8/12 | 20 | 8/12 | 20 |
| `1e-14` | 8/12 | 20 | 8/12 | 20 |
| `1e-15` | 10/12 | 22 | 10/12 | 22 |
| `1e-16` | 10/12 | 22 | 10/12 | 22 |

既定数学／標準数学で、この件数と反復数は同じだった。成功したケースは2反復、途中で方向を切り捨てたケースは1反復となった。`delta=2e-16`は現状doubleも全固定値も解けず、相対前進誤差は約0.707だった。

この族の初回では概ね`||w_after|| / ||w_before|| ≈ delta`なので、次の方向を保持するには`e < delta/8`が必要となる。これは行列側の小さい方向をどこまで保持するかの選択であり、機械epsilonに固定する必要はない。機械epsilonによる現行設定でも、floatでは`delta=2e-8`以下の方向を捨てている。

通常ケースは、実数6×6の優対角・Hilbert・非正規行列、複素数4×4の優対角・非正規行列を対象とした。full Kの直交化1回／2回、許容誤差0、`K=N/2, cycles=4`の再始動を比較した。**20件／型すべてで、11固定値の前進誤差・実残差・反復数は現状と同一だった**（両数学構成）。breakdownのフラグは一部で変わった。最大前進誤差約0.59のケースは再始動予算を使い切った非正規行列であり、基準から同じ結果である。

今回のGMRES測定からは「しきい値を機械epsilonより小さくすると必ず悪化する」とは言えない。正しい解が得られた場合、未収束の場合、数値的breakdownの状態を分けて評価する必要がある。

## 4. 固有値・固有ベクトル：共通値のスイープ

追加試験は3×3の通常対称・非正規・近接固有値（非対角成分delta=1e-6／1e-10、名目の固有値間隔2delta）・重複固有値・複素対・巡回行列・1e±12倍の行列を用いた。一般実数／一般複素数／対称Jacobiの適用可能な組合せが22件／型で、そのうち一般実数・複素数が16件。一般ソルバのQR上限128、逆反復上限30、Jacobiの上限10 sweep。

- 固有値誤差：格納入力に対するNumPyの固有値と全順列で対応付け、`max |lambda - lambda_ref| / ||A||_F`。
- 固有ベクトル残差：binary64で独立に計算した`max_j ||A*v_j-lambda_j*v_j||_2 / (||A||_F*||v_j||_2)`。
- 固有値収束は22件、ベクトル収束は独立した判定APIのある一般ソルバ16件の件数。Jacobiのベクトル残差も数値評価には含める。
- 「収束」は設定しきい値に対する状態。異なる`e`の収束件数だけでは精度の優劣を判定しない。

## 7. 調整可能な定数としての設計案

### 7.1 固定値は使用可能

反復法の停止条件には、使用者が要求する誤差や反復上限を反映できる。Netlibの解説も停止条件の`stop_tol`と最大反復数を使用者が与える形で説明している。[Templates for the Solution of Linear Systems, §4.2](https://www.netlib.org/templates/templates.html)

一方、LAPACKのQR deflationでは機械精度を使った保守的な基準が実装されている。これは丸め誤差程度の摂動を目指す既定方針の実例であり、本リポジトリで精度・計算量を調整する固定値を禁止する理由ではない。後半の判断は、本コードのしきい値の役割と今回の測定に基づく。[LAPACK DLAHQR](https://www.netlib.org/lapack/explore-html/d3/d03/dlahqr_8f_source.html)

### 7.2 最小の変更と用途別の変更

単一の設定値を使う最小案は、名前付き定数を定義して6箇所で`static_cast<T/Real>(...)`を使うものになる。値を保存するインスタンスメンバーは不要。

```cpp
// Example setting for investigation; not a universal default.
constexpr double ITERATIVE_SOLVER_THRESHOLD_BASE = 1.0e-7;
```

この案では8倍・32倍・平方根による連動が残る。より調整意図を明確にするなら、**最終的に比較する相対係数を直接定数にする**。

| 定数の例 | 適用箇所 | 調整の意味 |
| --- | --- | --- |
| `GMRES_BREAKDOWN_RELATIVE_TOLERANCE` | `breakdown_limit = constant * product_norm` | 保持する探索方向の小ささ |
| `DEFAULT_RELATIVE_TOLERANCE_EIGEN_SOLVER` | 一般QR・対称Jacobiの`relative_tolerance`初期値 | 非対角成分を無視する程度 |
| `DEFAULT_EIGENVECTOR_RELATIVE_TOLERANCE` | `eigenvector_tolerance`初期値 | 固有ベクトル残差への要求 |
| `DEFAULT_EIGENVECTOR_RELATIVE_SHIFT` | `small_value`初期値 | 逆反復の特異回避用摂動 |
| `DEFAULT_INNER_GMRES_RELATIVE_TOLERANCE` | `gmres_k_decay_rate`が未指定の場合 | 逆反復1回の線形求解への要求 |

例えば共通`e=1e-7`と等価な出発点なら、前3項は`8e-7`, `8e-7`, `3.2e-6`、後2項は約`3.16228e-4`, `0.00505964`となる。これは比較の出発点を示す例であり、同じ値を最終推奨値として固定するものではない。GMRES単独ではもっと小さいbreakdown係数が有効だったので、その調整だけを独立して行える構造が望ましい。

既存の`relative_tolerance`, `eigenvector_tolerance`, `small_value`, `gmres_k_decay_rate`による利用側からの調整は維持できる。固定値の背後で機械epsilonとの`max()`を取ると小さい値の指定が効かなくなるため、今回のような調整を意図する場合は、そのような自動補正を入れない。

すべての値を共通化しても、型の丸め特性や行列の条件数は同一にならない。型非依存の値を使うことと、型非依存の結果になることは別である。今回のデータから普遍的な1個の最適値は決められないが、固定定数による調整そのものは成立している。

### 7.3 反復上限・RAM・include

- 全GMRES測定で実反復数は`K * cycles`以内。定数を小さくしても上限は増やさない。
- 固有値のQR・逆反復・Jacobiも既存の反復上限を維持した。厳しい設定では上限まで実処理が続くケースがある。
- `sizeof`によるソルバ格納量は各型・サイズ・構成で全設定同じだった。実時間・スタックピークは今回は測定していない。
- 6箇所を固定定数へ置換する場合、Eigenヘッダの`<limits>`は不要になる。GMRES・LU・Choleskyでは`numeric_limits<T>::min()`を逆数の表現可能性の判定に使用するため保持する。`min()`の用途は今回の経験的なしきい値調整とは異なる。

## 8. 再現方法

[測定データと再実行手順](../test_vs/algorithm_improvements/results/epsilon_parameter_sweep/README.md)を参照。スクリプトは比較対象revisionのヘッダを一時領域へ展開し、製品ソースに直接書き込まない。assert、入力の16進出力、独立参照解を保存し、精度と収束状態を別々に確認できる。

用途別の固定値を組み合わせた追加調査は、[10: 用途別の固定しきい値による運用](10_independent_numerical_parameters.md)を参照。収束許容誤差・breakdown・逆反復シフトを切り離した試験と、固定値を既定値にする一時試作の検証を記録した。
